Restricted Mean Survival Time

Kaplan–Meier RMST and restricted mean time lost (RMTL) for right-censored survival data. Compare up to two groups at a common truncation horizon τ.

1. Survival data

Enter individual-level observations or select a local CSV/TSV file. Required columns: time,event; optional group. Event: 1 = event, 0 = right censored.

One observation per row. Times must be finite, nonnegative, in consistent units.
All calculations run in this browser. Uploaded files are not sent to a server. τ must not exceed the largest observed time within either group; values beyond observed follow-up are not extrapolated.

2. Estimates

Load an example or enter survival observations, then select Calculate RMST.

Kaplan–Meier survival curves

Descriptive, unadjusted KM estimates only. No confidence intervals or hypothesis tests. The RMST difference is comparison minus reference (alphabetical group order); positive means greater observed event-free time under this event definition.

RMST(τ) = ∫₀ᵗᵃᵘ Ŝ(t) dt; RMTL(τ) = τ − RMST(τ). This is a research/statistical utility, not a clinical decision rule. Censoring should be non-informative for Kaplan–Meier interpretation. Source repository.
